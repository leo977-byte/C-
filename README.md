#  Competitive Programming & Problem Solving

Welcome to my competitive programming repository! This repository serves as an archive of my solutions to algorithmic problems, Codeforces Gyms, LeetCode practice, and specialized topics such as **Dynamic Programming**.

---

##  Topics & Focus Areas

- **Dynamic Programming (DP):** Classical and advanced DP patterns, including 1D/2D DP, DP on trees, bitmask DP, and optimization techniques.
- **Codeforces Gyms:** Full contest archives, mashups, and qualification gym solutions.
- **LeetCode:** Data structures and algorithmic problem sets sorted by difficulty.
- **Data Structures & Algorithms:** Graphs, Trees, Disjoint Set Union (DSU), Segment Trees, Binary Search, Math, and Number Theory.
